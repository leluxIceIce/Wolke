# Wolke 1.7

The first public beta brings a native SoundCloud desktop widget to macOS in **1×1, 2×1, and 2×2**, with a sleeping orange cat around the cover.

- See the current track, artwork, artist, and running time.
- Play or pause, skip tracks, seek by 15 seconds, and toggle likes from the desktop.
- Open the SoundCloud playlist chooser with the playlist button.
- Control a SoundCloud tab from the Safari toolbar, or let Wolke try to resume it in a background tab when you close the original.

**Download `Wolke-1.7.zip` below.** This build targets Apple silicon Macs running macOS 14 or later. Follow the README to enable the local Safari extension for soundcloud.com. Safari resets its unsigned-extension setting when you quit.

The package and the player and handoff tests have been verified. Direct desktop playback in this build still needs an end-to-end test.
